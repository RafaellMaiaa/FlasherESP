Modelos ZPL no Sistema
    Guia: Etiquetas ZPL

    Para que o sistema consiga injetar os dados na etiqueta, é necessário utilizar variáveis de substituição no molde.

    1. Inserir as Variáveis

    No ZebraDesigner, crie caixas de texto com os seguintes códigos exatos:

    • @MAC@ → Injeta o MAC Address lido
    • @SN@ → Injeta o Serial Number gerado
    • @IMEI@ → Injeta o IMEI lido
    • @CIMI@ → Injeta o CIMI lido
    2. Exportar o Ficheiro

    A aplicação necessita do código RAW da impressora:

    1. Vá a Ficheiro > Imprimir.
    2. Marque a opção "Imprimir para Ficheiro".
    3. Guarde o ficheiro no formato .prn e faça o upload nesta página.
